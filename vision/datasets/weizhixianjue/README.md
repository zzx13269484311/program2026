# 危知先觉六类目标数据集

## 1. 数据集目标

训练一个面向化工实验室模拟场景的 YOLO11n 检测模型，统一识别以下六类目标：

| ID | 英文标签 | 中文含义 | 典型对象 |
|---:|---|---|---|
| 0 | `person` | 人员 | 进入作业区域的人员 |
| 1 | `lab_coat` | 实验服 | 人员躯干上的实验服 |
| 2 | `goggles` | 护目镜 | 人员头部或眼部的护目镜 |
| 3 | `obstacle` | 通道障碍物 | 阻挡通道的纸箱、推车、杂物 |
| 4 | `smoke` | 烟雾 | 可见烟雾区域 |
| 5 | `fire` | 火焰 | 可见明火区域 |

本数据集不直接设置“未戴护目镜”类别。是否佩戴护目镜由 `person` 与 `goggles` 的空间关联和持续时间规则判断。

图片和标签文件必须同名。例如：

```text
images/train/scene01_0001.jpg
labels/train/scene01_0001.txt
```

## 3. YOLO 标签格式

每张图片对应一个 `.txt` 标签文件，每行一个目标：

```text
class_id x_center y_center width height
```

所有坐标均使用 0 到 1 之间的归一化数值：

- `class_id`：0 到 5。
- `x_center`：目标框中心点横坐标 / 图片宽度。
- `y_center`：目标框中心点纵坐标 / 图片高度。
- `width`：目标框宽度 / 图片宽度。
- `height`：目标框高度 / 图片高度。

示例：

```text
0 0.512 0.486 0.240 0.620
2 0.518 0.302 0.090 0.055
```

没有目标的负样本也必须创建**空 `.txt` 文件**，不要缺少标签文件。

## 4. 标注规则

### 4.1 `person`

- 标出完整可见人体范围。
- 被遮挡时只标可见部分，不凭空补框。
- 极小、无法辨认的人不标。

### 4.2 `lab_coat`

- 标在人员躯干外层的实验服区域。
- 实验服被手臂或桌面遮挡时，标可见部分。
- 普通外套、短袖和便服不能标为实验服。

### 4.3 `goggles`

- 标在人员眼部或头部佩戴的护目镜区域。
- 手持护目镜但未佩戴时，不标为佩戴状态。
- 普通眼镜不能标为护目镜。

### 4.4 `obstacle`

- 只标位于通道、门口或作业通行区域的障碍物。
- 正常靠墙摆放、不阻挡通行的物品不标。
- 同一障碍物由多个物体组成时，可以合并为一个外接框。

### 4.5 `smoke`

- 标出画面中可见烟雾的整体区域。
- 少量无法确认的雾气不应标为烟雾。
- 模拟烟雾必须使用安全烟雾设备。

### 4.6 `fire`

- 标出可见明火区域。
- 演示只能使用安全的模拟火焰或受控道具，不使用真实危险火焰。

## 5. 数据划分规则

按**视频或场景**划分训练集、验证集和测试集，不要按随机帧划分。

推荐比例：

```text
train 70%
val   15%
test  15%
```

同一个场景、同一个视频或几乎相同的连续帧不能同时出现在训练集和测试集中，否则会产生数据泄漏，导致指标虚高。

## 6. 采集要求

- 目标总量：300 到 500 张起。
- 场景：危化品取用区、加热区、通道、门口和实验台。
- 光照：正常灯光、弱光、侧光和局部反光。
- 角度：正面、侧面、俯视和远距离。
- 遮挡：人员互相遮挡、实验服被遮挡、护目镜反光。
- 负样本：无风险的正常作业场景也要保留。
- 不使用真实危险化学品、真实明火或真实危险烟雾。

## 7. 数据准备流程

### 7.1 创建目录

```powershell
Set-Location "D:\program\weizhixianjue"
.\.venv\Scripts\python.exe .\scripts\init_dataset.py
```

### 7.2 放入原始素材

将未标注图片先放入：

```text
vision/datasets/weizhixianjue/raw/incoming/
```

### 7.3 标注并划分数据

使用支持 YOLO 格式的标注工具完成标注，再按场景划分到 `images/train`、`images/val`、`images/test` 和对应 `labels` 目录。

### 7.4 验证数据集

```powershell
Set-Location "D:\program\weizhixianjue"
.\.venv\Scripts\python.exe .\scripts\validate_dataset.py
```

验证脚本会检查：

- 图片和标签是否成对。
- 类别 ID 是否为 0 到 5。
- 坐标是否归一化。
- 目标框是否越界。
- 图片是否可以正常解码。
- 是否存在跨训练/验证/测试集的重复图片。
- 各集合和各类别的数量统计。

验证报告保存到：

```text
vision/datasets/weizhixianjue/reports/validation.json
```
